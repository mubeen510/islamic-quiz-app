# Islamic Quiz App

This project is a web-based Islamic Quiz Application developed using HTML, CSS, and JavaScript.

## Features
- Multiple choice questions
- Timer-based quiz system
- Score calculation
- Result summary screen
- LocalStorage for storing high scores

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Git & GitHub

## How to Run
1. Download or clone the repository
2. Open index.html in any modern browser
